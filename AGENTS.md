# Akibwa Core Site Notes

This repository is the public `akibwa.com` website.

- Treat everything committed here as public.
- Do not add private health data, local dashboard exports, credentials, tokens, `.env` files, booking references, account numbers, raw source exports, or similar secrets.
- Keep Vitals as a public-safe case study only; the working dashboard, generated health snapshots, and source data belong outside this repo.
- The site is a static Next.js export (`output: "export"`) deployed to GitHub Pages from `main`.
- Build check: `npm run build`.
