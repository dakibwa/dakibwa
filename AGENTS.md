# Akibwa Core Site Notes

This repository is the public `akibwa.com` website.

- Treat everything committed here as public.
- Do not add private health data, local dashboard exports, credentials, tokens, `.env` files, booking references, account numbers, or similar secrets.
- Keep the Health Dashboard as a public case study only; the working dashboard and source data belong outside this repo.
- The site is a static Next.js export (`output: "export"`) deployed to GitHub Pages from `main`.
- Build check: `npm run build`.
