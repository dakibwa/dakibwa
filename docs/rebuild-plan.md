# Dakibwa rebuild plan

1. Strip the app back to a single music-first experience: hero, constellation, selected-artist detail, and a small listening ledger.
2. Keep Last.fm as the primary data source, but make the fallback data feel like Daniel rather than generic demo filler.
3. Replace the oversized mixed-provider components with smaller modules for data fetching, graph shaping, and rendering.
4. Rework the visual language toward a dark, atmospheric, slightly esoteric art-object feel.
5. Remove stale dependencies and legacy framing, then run a full production build and commit the result.
